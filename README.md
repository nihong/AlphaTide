# AlphaTide: AI 驱动的“10倍股”自动搜寻哨兵

AlphaTide 是一个全自动化的 AI 投资决策支持系统，专门设计用于在 A 股和港股市场中寻找具备“10倍股”潜力的优质标的。它结合了深度基本面筛选、市场轮动预测、技术面验证以及大模型（DeepSeek）的自动化点评。

## 🌟 核心功能

- **🌍 全球宏观视野**：自动追踪美股（纳指、半导体指数）与离岸人民币汇率，感知全球资金流向与风险偏好，为 A/HK 市场决策提供全球背景。
- **🚦 牛熊双轨红绿灯**：实时监控大盘（沪深300/恒指）趋势。牛市（绿/黄灯）开启【右侧突破游资引擎】，熊市（红灯或空头环境）自动切断突破逻辑，全面开启【左侧防守引擎】（超跌反弹），以此规避熊市“假突破”陷阱。

- **🔥 双核杠铃策略 (Barbell Strategy)**：
    - **潜伏蓄势池**：分析资金流向，锁定“资金大幅流入但价格未涨”的低位安全板块。
    - **动量热门池**：扫描全市场换手率，锁定“高活跃、强爆发”的主升浪概念板块。
- **🌟 题材共振智能识别 (Concept Resonance)**：自动交叉比对多维板块，若个股同时横跨多条热门主线（如：AI+出海），将触发共振加权并优先推荐。新增“新晋题材”探测，优先锁定过去3天未出现的新热点。
- **🧬 10倍股基因筛选**：
    - **盈利能力**：牛市 ROE > 3%，熊市进入防守时严苛要求 ROE > 5%（侧重困境反转潜力）。
    - **利润质量**：净现比 > 0.5（确保赚的是真钱）。
    - **业绩前瞻**：合同负债（预收款）高增长，且近3期净利润增速呈现加速斜率（最新>前期>前前期）。
    - **估值安全**：PE 处于历史 5 年百分位 < 85%，拒绝估值泡沫。
- **📈 多维强度与风控验证**：
    - **RS 相对强度**：筛选走势强于大盘的个股，确保是领涨标的。
    - **流动性过滤**：排除日均成交额 < 5000 万的冷门股。
    - **技术面双轨切换**：
        - **牛市/震荡市**：站稳 EMA10，近期有放量大阳线突破且正在缩量回踩，MACD 动能向上。
        - **熊市防守**：寻找极度恐慌错杀，乖离率 BIAS < -15% 或 RSI < 30，且 MACD 绿柱缩短。
- **💼 智能仓位管理 (Position Sizing)**：基于 ATR (平均真实波幅) 计算个股波动率，自动输出“风险平权”下的建议买入仓位（%），拒绝满仓单吊。
- **🛑 多轨卖出预警**：
    - **移动止损**：最高点回撤基于 ATR 动态止损（吊灯止损法）。
    - **激进型**：破 EMA10 止损（动能衰退）。
    - **保守型**：乖离率过大（BIAS > 15%）止盈（情绪过热）。
- **🧠 AI 自动研报与舆情引擎**：
    - **深度点评**：集成 DeepSeek API，对精选个股生成专业的财务/技术/行业深度研报。
    - **🌡️ 全市场舆情体温**：每日自动抓取热点板块最新 50+ 条核心新闻，由 AI 实时判读情绪分与参与建议。
- **📅 历史策略追踪看板**：系统每次执行后会自动解析历史报告，更新生成全局汇总大表 (`reports/master_summary.md`)，方便复盘历史推荐表现与大盘状态。


## 🌎 跨市场双重逻辑 (A股 vs 港股)

针对 A 股的“题材市”和港股的“流动性市”，AlphaTide 构建了两套截然不同的量化漏斗，可通过命令行参数 `--market` 灵活切换。

### 🇨🇳 A 股：双核杠铃与题材共振
*   **策略核心**：寻找游资与机构的“抱团”共识。
*   **选股池**：通过资金流向获取“蓄势板块”，通过换手率获取“热门概念”。
*   **题材加权**：自动识别横跨多主线（如 AI+出海）的共振标的，给予最高推荐权重。
*   **基本面偏好**：要求高成长（利润增速>20%）和真金白银（净现比>1）。

### 🇭🇰 港股：核心资产与流动性狩猎
*   **策略核心**：在缺乏流动性的离岸市场中寻找确定性的蓝筹白马。
*   **选股池**：彻底抛弃板块概念，直接全市场锁定“单日成交额 Top 50”的高流动性池，规避“仙股/老千股”陷阱。
*   **基本面偏好**：要求盈利质量稳定（ROE>10%）和资产健康（负债率<60%）。
*   **波动防御**：采用更严苛的 ATR 仓位平权和高位回撤防线，应对港股无涨跌幅限制的剧烈波动。

## 🚀 快速启动

### 1. 环境准备
```bash
git clone https://github.com/nihong/AlphaTide.git
cd AlphaTide
pip install -r requirements.txt
```

### 2. 配置 API Key
复制 `.env.example` 为 `.env`，填入您的 DeepSeek Key：
```bash
cp .env.example .env
# 编辑 .env 文件，填入 DEEPSEEK_API_KEY=sk-xxxx
```

### 3. 运行自动化扫描
- **A 股扫描 (默认)**：
  ```bash
  python3 main.py --auto
  ```
- **港股扫描**：
  ```bash
  python3 main.py --auto --market HK
  ```
- **历史回测模式** (时光机功能，可指定日期)：
  ```bash
  python3 main.py --auto --date "2024-03-01"
  ```

## ⏰ 自动化运行 (尾盘买入法)
建议将本项目作为 **OpenClaw** 或 **QClaw** 的一个 Skill (技能) 接入，实现云端定时任务与消息推送。
- **A 股定时触发**：建议设置在每个交易日 **14:50** 运行 `python3 main.py --auto`，并在 **14:55** 完成买卖。
- **港股定时触发**：建议设置在每个交易日 **15:50** 运行 `python3 main.py --auto --market HK`，并在 **15:55** 完成买卖。
- **消息推送**：可配置 Webhook 将 `reports/` 下生成的每日决策日报推送至飞书、钉钉或微信。
- **本地 `crontab` 设置示例**：
  ```bash
  # A 股：周一至周五 14:50 运行
  50 14 * * 1-5 cd /你的路径/AlphaTide && /usr/bin/python3 main.py --auto
  
  # 港股：周一至周五 15:50 运行
  50 15 * * 1-5 cd /你的路径/AlphaTide && /usr/bin/python3 main.py --auto --market HK
  ```

## 📈 投资策略说明
本项目倡导**“基本面选股 + 资金流择时 + 趋势控仓”**的生产级量化理念。
- **双核选时机**：结合均线与成交量（量价确认）判断大盘，杠铃策略挖掘蓄势与热门板块。
- **智能选好股**：硬性指标过滤地雷（净现比>1，流动性>1亿），题材共振发现龙头。
- **铁血控风险**：ATR风险平权定仓位，最高点回撤绝对止损，趋势破位清仓，过热乖离分批。
