# AlphaTide 🌊

**AlphaTide V8.0: The Bullwhip & Bottleneck Sniper** (牛鞭效应与极早期财务穿透系统)

AlphaTide is an institutional-grade, fully autonomous quantitative investment framework. 
Version 8.0 marks a massive paradigm shift: It completely abandons lagging financial reports and macroscopic cycle predictions. Instead, it weaponizes **Alternative Data** and **Large Language Models (LLMs)** to identify extreme supply-demand mismatches (The Bullwhip Effect) and supply chain bottlenecks, buying the absolute leaders exactly as they break out.

## The Alpha Philosophy (V8.0 Paradigm Shift)

True alpha is generated by capturing the exact moment an industry enters an "Epic Capacity Shortage", causing prices to explode non-linearly:
1. **Supply Chain Bottleneck Discovery (AI-Driven)**: Scraping thousands of daily industry reports to let AI detect keywords like "spot price surging", "inventory depleted", and "long capacity expansion cycles".
2. **Right-Side Momentum (RPS + VCP)**: We never buy the dip. We only buy the absolute sector leaders showing Top 10% Relative Price Strength (RPS > 90) that are forming tight Volatility Contraction Patterns (VCP).
3. **The "Davis Double-Kill" Escape Plan**: Supply chain stocks ALWAYS peak 6-12 months before their earnings peak. Our system ignores optimistic PE ratios at the top and ruthlessly executes sells using a strict **2.5x ATR trailing stop** and **20-day EMA breakdown**.

## V8.0 Architecture (Simplified & Lethal)

Following the "Great Purge" of legacy code, AlphaTide now operates via a highly concentrated, 3-module pipeline:

1. **📡 `src/industry_validator.py`**: The high-speed data pipeline. Bypasses slow API wrappers to directly fetch raw JSON broker reports from EastMoney. **(Equipped with Akshare Disaster Recovery Fallback to prevent IP blocks/API changes)**.
2. **🧠 `src/bullwhip_engine.py`**: The Core Brain. Integrates LLM prompting to find the "choke-points", calculates RPS/VCP for stock selection, and calculates the 2.5x ATR chandelier exit.
3. **⚙️ `main.py`**: The master orchestration script running the daily lifecycle.
