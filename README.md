# AlphaTide 🌊

**AlphaTide V5.0: The Dual-Brain Momentum Sniper** (双轨制主客观多因子融合量化系统)

AlphaTide is an institutional-grade, fully autonomous quantitative investment framework designed for A-shares, HK-shares, and Global Macro ETFs. It abandons both "blind technical indicator brute-forcing" and "pure AI hallucination" in favor of a modern **AI-Assisted Quantitative Architecture** with strict Macro hedging.

## The Alpha Philosophy (V5.0 Paradigm Shift)

We believe that true alpha comes from tracking real institutional money, and using AI only as a forensic auditor, rather than a dictator.
True alpha is generated by:
1. **Ironclad Universe Filtering**: Stripping out garbage ST stocks and illiquid micro-caps, ensuring we only trade in highly liquid pools (allowing explosive sub-new stocks).
2. **Quant Radar (Objective Edge)**: Scanning for 5-10 day rolling institutional accumulation (volume spikes without price explosion). Money doesn't lie.
3. **AI Forensic Auditor (Subjective Edge)**: Using Large Language Models (DeepSeek) to read macro news and *audit* the quant pool. If a stock has massive volume but no fundamental logic, the AI vetoes it.
4. **Absolute Defense**: Executing 1x leverage macro shorting (融券对冲) when the broader market enters a Bear Regime, ensuring capital preservation.

## V5.0 Architecture

AlphaTide operates via 4 autonomous core modules:

1. **🛡️ Universe Screener (`src/universe_screener.py`)**: The Bouncer. Filters 5300 stocks down to ~800 highly liquid, non-ST core assets.
2. **📡 Quant Radar (`src/quant_radar.py`)**: The Detective. Scans the core universe for 10-day institutional accumulation footprints (VWAP/TWAP stealth buying).
3. **⚖️ AI Auditor (`src/brain_nlp.py`)**: The Judge. Reads the news and cross-examines the Quant Radar's findings. Vetoes manipulated pump-and-dumps; approves stocks with solid policy/macro tailwinds.
4. **⚔️ Execution Engine (`src/execution_engine.py`)**: The Sniper. Executes trades and rigidly enforces risk management (ATR trailing stops, logic-invalidation exits, and systemic macro hedges).

## Quick Start
```bash
# Clone the repository
git clone https://github.com/nihong/AlphaTide.git
cd AlphaTide

# Install dependencies
pip install -r requirements.txt

# Run the V5.0 live pipeline
python3 src/main_v5.py
```

- `.env` and local caches are ignored via `.gitignore`.
