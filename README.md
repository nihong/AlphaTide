# AlphaTide 🌊

**AlphaTide V4.5: AI-Driven Event & Flow Arbitrage System with Macro Hedge** (AI 驱动的逻辑共振与资金追随系统)

AlphaTide is an institutional-grade, fully autonomous quantitative investment framework designed for A-shares, HK-shares, and Global Macro ETFs. It abandons traditional "blind technical indicator brute-forcing" in favor of a modern **AI-Driven Fundamental Quant** approach with strict Macro hedging.

## The Alpha Philosophy

We believe that true alpha cannot be found by blindly crossing moving averages on 5000 stocks. 
True alpha is generated by:
1. **Discovering Deep Logic**: Utilizing Large Language Models (LLMs) to read top-tier brokerage reports and government policies to identify decadal megatrends or imminent turnarounds.
2. **Falsification via Alternative Data**: Verifying the narrative using hard physical data (e.g., Baltic Dry Index, PMI, Semiconductor Sales).
3. **Voting via Smart Capital**: Only entering the market when the "Smart Money" aggressively confirms the narrative through massive volume inflows and relative strength breakouts.
4. **Absolute Defense**: Executing 1x leverage macro shorting (融券对冲) when the broader market enters a Bear Regime, ensuring capital preservation.

## V4.5 Architecture

AlphaTide operates via 4 autonomous core modules:

1. **🧠 AI Research Brain (`src/brain_nlp.py`)**: The idea generator. Scrapes news, extracts logic via LLM, and maintains a highly curated 30-50 stock `Dynamic Watchlist`.
2. **🕵️ Truth Filter (`src/falsification_filter.py`)**: The skeptic. Kills ideas if underlying macroeconomic or industry-specific alternative data (Akshare) does not support the narrative.
3. **💸 Capital Flow Voter (`src/capital_flow_voter.py`)**: The timer. Ranks surviving stocks based on institutional block trades, sector resonance, and right-side momentum.
4. **⚔️ Execution Engine (`src/execution_engine.py`)**: The sniper. Executes trades and rigidly enforces risk management (ATR trailing stops, logic-invalidation exits, and systemic macro hedges).

## Backtesting Framework

V4.5 introduces decoupled, highly rigorous backtesting engines to validate physical defense without relying on expensive live LLM calls:
- `scripts/monte_carlo_backtest.py`: "Monkey Brain" stress test injecting random stocks to prove Execution Engine defense (<15% max drawdown).
- `scripts/real_market_6yr_backtest.py`: 6-year Hindsight AI test simulating institutional macro rotations.
- `scripts/recent_60d_backtest.py`: Live-combat replay over the last 60 turbulent days.

## Quick Start
```bash
# Clone the repository
git clone https://github.com/nihong/AlphaTide.git
cd AlphaTide

# Install dependencies
pip install -r requirements.txt

# Run the live pipeline
python3 src/main_v4.py

# Run backtests
python3 scripts/recent_60d_backtest.py
```
